# MCP Athena GraphKit

O servidor opcional `mcp_server.py` (raiz do projeto) usa `mcp.server.fastmcp.FastMCP` via stdio. Instale `requirements-mcp.txt`. Ferramentas: `list_themes`, `render_diagram` (somente flowchart/graph compatíveis) e `prepare_documentation` (Markdown + imagens PNG base64). Não presumir MCP remoto, instalação no ChatGPT ou acesso a documentos Markdown.
