# Perguntas frequentes (FAQ)

## Como mantenho as posições dos elementos ao recarregar?

Arraste os elementos na aba **Construtor visual** e clique em **Salvar projeto**. Aguarde a confirmação antes de atualizar a página. Se outra pessoa salvou alterações enquanto você editava, revise a versão atual antes de tentar salvar novamente.

## Como escondo os pontos no fundo da área de desenho?

Clique em **Grade**, ao lado do zoom. Clique em **Salvar projeto** para lembrar a escolha naquele diagrama.

## Onde estão os projetos e diagramas que recebi?

Abra **Compartilhamento** no cabeçalho ou **Minha conta → Projetos compartilhados**. Um diagrama compartilhado por si só abre em uma página própria.

## O que cada permissão permite?

| Permissão | O que permite |
| --- | --- |
| Visualizar projeto | Abrir e exportar o projeto e seus diagramas. |
| Editar projeto | Visualizar e salvar alterações no projeto e seus diagramas. |
| Visualizar diagrama | Abrir o código e a prévia do diagrama compartilhado. |
| Editar diagrama | Visualizar e salvar o título e o código do diagrama compartilhado. |

O proprietário administra as concessões em **Permissões**. A remoção de uma concessão pode deixar ativo um acesso recebido por outro grupo ou organização. Para uma concessão direta por e-mail, o destinatário precisa ter o endereço confirmado.

## Preciso receber um e-mail para criar a conta?

Na configuração padrão, escolha **Criar conta** e preencha os dados na própria aplicação. Se o servidor estiver sem envio de e-mails e você esquecer a senha, procure o responsável pela instalação.

## Qual opção devo usar para guardar uma cópia?

- **Exportar projeto** baixa o projeto atual em JSON, que pode ser aberto com **Importar projeto**.
- **Backup ZIP** reúne os projetos disponíveis na conta em um arquivo ZIP.
- **Exportar documentação** reúne o Markdown e as imagens referenciadas. Para preservar os vínculos, extraia o ZIP e mantenha a pasta `imagens/` junto ao documento.
